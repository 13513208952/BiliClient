# BiliClient

本项目是bilibili的一个第三方客户端，并精简了上游部分功能，增加了下载功能（下载会默认下载到系统默认视频文件夹路径，顺便移除了缓存功能）。
顺便一提，我们顺便加入了一个定制推送源-怀旧推荐。怀旧推荐会使用我们从internet archive 和common crawl采集得到的视频列表，并进行筛选、精简和定期剔除失效视频，并充分打乱了顺序。
这意味着你可以用这个模式看看6年之前疫情之前的00后们看到的B站是什么样子的，这个模式没有推送算法。推送源详情请看https://github.com/13513208952/Bili20HistoryVideoAV 项目。
注意：怀旧推荐源我们会进行一些过滤，常见被过滤情况包括：擦边，热门明星（真爱粉不需要它也能找到对应人士），时尚，娱乐圈，反智，教程（请学习比较新的教程），舞蹈，健身，部分国漫，老旧游戏攻略，部分游戏（绝大部分为已关服游戏），电竞（想看建议自行直接搜索对应比赛视频），部分顶流日常系up主（大部分到现在仍然在积极更新，大量推送容易疲劳，请爱好人士自行关注观看）等。


## 0.2.2 版本说明

- 1.加入重复推送拦截功能
- （每半年进行自动重置，会统计B站累计向你重复推送了多少次，和你的首页总共出现了多少个视频，位于“推荐流设置”底部）
- 2.对于怀旧推荐模式的一系列更新
- （包括首页三点菜单精简和定制修改，基于屏蔽词的自定义过滤，怀旧推荐专用up主黑名单，怀旧推荐专用视频屏蔽，）
- 3.手机端视频有效性协助验证（常规用户默认关闭此功能）
- 4.加入评论筛选功能，建议使用其屏蔽近一年新创建账号和低于等于lv2的账号，而且支持按用户名关键词屏蔽
- （有效反制鱼灾评论）（位于其他设置，名称为“评论筛选”）
- 5.推送源所属项目会在后期发布更新。
- （我们的屏蔽词会提前直接对推送源进行过滤，因此这里不会也不需要发布任何屏蔽词）
- 评论筛选功能理论上会轻微影响网络效率，不过实测影响较小，建议普通用户保持开启。

## 0.2.1 版本说明

之前的版本是拿AI搓出来的，但是很烂，但是我们后来才发现这个更强大的开源项目，就借来源码用了。
本次是基于上游piliplus仓库的对本项目的重构版本，也可以视作对原仓库的风味版本，后面还会加入更多的一些小功能。

`0.2.1` 修复了下载末段音视频合流失败：恢复经旧版 BiliClient 验证的 FFmpegKit 无损合流，并保留原始视频、音频编码，不改变播放器实现。
